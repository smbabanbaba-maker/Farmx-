# FarmX Community verification

The new `/community` route renders a real-data-only empty state with “Welcome to FarmX Community”, an honest explanation, and Create First Post. It renders Latest, Popular, Following feed tabs; horizontal topic chips; a prominent Create a Community post entry point; and a safety separation notice clarifying that Market remains the listing system and Community does not process private payments.

The Community search control opens a mobile-friendly input with Search posts, topics, people… and a Search button. The existing six-item bottom navigation remains visible without covering the page.
The full Create Post modal opens from the Community entry point. It shows a public-safety note, a 5,000-character editor, Post type and Topic selectors, Photo/video upload, Share listing, optional State/City/Area, Cancel, and Post to Community controls. It is mobile-sized with sticky header/footer and the existing bottom navigation remains visible behind the modal.
The composer Post type menu exposes Text post, Question, Farm update, Advice / Knowledge, Discussion, Photo post, Video post, and Announcement. The Topic menu exposes the scalable registry across Agriculture, Technology, Business, and General groups.
